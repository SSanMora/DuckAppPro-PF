README – DuckApp Pro

1. Descripción del proyecto

DuckApp Pro es una aplicación de escritorio desarrollada en Java (IntelliJ) utilizando la biblioteca Swing. Esta aplicación que simula carreras de patos, permite registrar participantes, crear carreras, ejecutar simulaciones visuales, consultar las estadísticas de los resultados obtenidos y además exportarlos directamente a tu escritorio. El sistema está organizado siguiendo el patrón de diseño MVC (Modelo – Vista – Controlador), lo que permite una separación clara entre la lógica del programa, la interfaz gráfica y el control de eventos.

3. Funcionalidades principales

A continuación una lista de las funciones de la aplicación:
• Gestión de participantes (registro, búsqueda y eliminación)
• Gestión de carreras
• Simulación visual de carreras de patos
• Cálculo de ganadores y podios
• Visualización de estadísticas
• Exportación de estadísticas en archivo .txt
• Navegación entre vistas desde un único frame


4. Pasos de ejecución

1. Primero, abrir el proyecto en un entorno de desarrollo compatible con Java (por ejemplo, IntelliJ IDEA o NetBeans)
2. Luego, ubicar la clase principal llamada "main" en el paquete DuckAppPro
4. Siguiente, ejecutar el método main
5. Finalmente, utilizar el menú principal para navegar por las diferentes funcionalidades del sistema


5. Consideraciones técnicas

• Lenguaje de programación: Java
• Interfaz gráfica: Swing
• Estructura del proyecto: patrón MVC
• Ejecución: aplicación de escritorio
